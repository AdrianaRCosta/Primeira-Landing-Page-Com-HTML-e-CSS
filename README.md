# 🌐 Landing Page em HTML e CSS

Este projeto é uma **landing page estática** desenvolvida com HTML5 e CSS3. 
O objetivo é apresentar um layout visualmente agradável com estrutura organizada e estilização personalizada.


## ✨ Funcionalidades

- Estrutura semântica com HTML5
- Estilização com CSS3
- Banner com gradiente e logo
- Tipografia e cores personalizadas

  ## 📱 Responsividade

> ⚠️ Esta versão **não possui responsividade**.  
A página foi desenvolvida com foco em visualização em telas maiores (desktops).  
A responsividade será implementada em versões futuras utilizando **media queries** e técnicas de layout flexível.
